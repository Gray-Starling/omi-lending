# Архитектура проекта

## Назначение
Русскоязычный сайт OMI о комплексном оснащении ванных комнат: мебель собственного производства, сантехника и интерьерные решения. На главной указана география — Владивосток.

## Структура
- `index.html` — одностраничный лендинг: навигация, описание продуктов и мебели, шоурум, варианты решений, отзывы, FAQ, предложение, форма контакта, юридические ссылки и блок cookie.
- `assets/css/style.css` — стили страницы, адаптивные состояния и дизайн-токены.
- `assets/js/script.js` — клиентские интерактивы: мобильная навигация, появление элементов при прокрутке, слайдеры/карусели, раскрытие отзывов и логика формы.
- `assets/img/`, `assets/icons/`, `assets/fonts/`, `assets/video/` — локальные изображения, SVG, шрифты и видео.
- `politika.html`, `soglasie.html`, `cookies.html` — файлы для правовых документов; на момент описания они пустые.
- `robots.txt`, `sitemap.xml` — базовые файлы индексации сайта.

## Технологии и запуск
- Обычные HTML, CSS и JavaScript без видимого фреймворка или сборщика.
- Внешние зависимости и шаг сборки по текущей структуре не обнаружены.
- Для локального просмотра достаточно открыть `index.html` в браузере или обслужить каталог любым статическим HTTP-сервером.

## Визуальная основа
- Основные цвета и семейства шрифтов заданы CSS-переменными в начале `assets/css/style.css`.
- Шрифты подключаются локально: Mulish, Sansation и Tenor Sans.
- Контент и интерфейс ориентированы на русский язык и мобильную адаптивность.
