# Product Context — OMI Lending

## Зачем существует
Потенциальный клиент во Владивостоке ищет комплексное оснащение ванной (мебель + сантехника + монтаж) с индивидуальным подходом. Лендинг должен:
- Убедить, что OMI — надёжный производитель с собственным цехом.
- Показать примеры работ.
- Ответить на частые вопросы.
- Собрать контакт для консультации/расчёта.

## Как это работает сейчас
Одностраничник с плавным скроллом (CSS `scroll-behavior: smooth`). Каждый блок — самостоятельная секция с id-якорем. Анимации появления `.fade` срабатывают при пересечении порога 15% через IntersectionObserver. Форма собирает имя и телефон, валидирует на стороне клиента (маска телефона, проверка длины), при успехе показывает `alert` (временное решение, не бэкенд). Cookie-баннер хранит согласие в `localStorage`.

## UX-цели
- **Мобильная адаптивность:** бургер-меню, адаптивные изображения, медиа-запросы.
- **Доступность:** `aria-label`, `prefers-reduced-motion: reduce` — отключает анимации при настройках ОС.
- **Плавность:** появление элементов с `opacity`/`transform`, CSS-переменная `--ease` для анимаций.
- **Социальное доказательство:** отзывы с 2GIS, рейтинг звёздами, фото клиентов.
- **Прогревание:** блоки идут в логике «проблема → решение → примеры → FAQ → предложение → контакт».

## Сценарии пользователя
1. **Первичное знакомство:** скроллит от hero до формы, знакомится с услугами.
2. **Целевой выбор:** входит через меню в блок «Мебель» → «Сборка» → хочет кастомизацию.
3. **Покупка со скидкой:** видит спецпредложение → клик «Получить скидку» → скролл к форме с предзаполненной темой.
4. **Изучение отзывов:** переходит в блок отзывов, листает карусель, переходит на 2GIS.
5. **Повторный визит:** cookie уже приняты, баннер не показывается.

## Текущие ограничения
- Форма не отправляется на сервер (action="#", method="post", novalidate — заглушка).
- Правовые страницы (`politika.html`, `soglasie.html`, `cookies.html`) пусты.
- js-код содержит незначительные дубли (два блока IntersectionObserver для `.fade`).
- Нет внешней аналитики (счётчики, пиксели не обнаружены).
