# System Patterns — OMI Lending

## Архитектура сайта
**Тип:** статический одностраничный лендинг (`index.html`), обслуживаемый любым HTTP-сервером. Нет серверной логики, базы данных, шаблонизатора или сборщика.

```
/
├── index.html               # единственная страница (11 блоков)
├── assets/
│   ├── css/
│   │   └── style.css        # все стили (≈2500 строк)
│   ├── js/
│   │   └── script.js        # все скрипты (≈720 строк)
│   ├── img/                 # 17 изображений (hero, проекты, аватарки, промо)
│   ├── fonts/               # локальные шрифты: Mulish, Sansation, Tenor Sans
│   ├── icons/               # SVG-иконки (favicon, logo, соцсети, стрелки)
│   └── video/               # 1 видео (раковина)
├── politika.html            # пустая заглушка
├── soglasie.html            # пустая заглушка
├── cookies.html             # пустая заглушка
├── robots.txt               # Allow: /, Sitemap: https://omi-shop.ru/sitemap.xml
├── sitemap.xml              # 4 URL (главная, правовые), lastmod 2026-10-03
└── screenshots/             # рабочие скриншоты для Sonnet (в .gitignore, не отслеживаются)
```

## CSS-паттерны
- **Дизайн-токены:** все цвета, шрифты, радиусы и easing вынесены в `:root` (≈33 переменные).
- **Типографика:** заголовки — Tenor Sans, тело — Mulish, UI-элементы (кнопки, навигация) — Sansation.
- **Анимации:** класс `.fade` — прозрачность + сдвиг, срабатывает в `.visible` при скролле.
- **Адаптив:** media-queries внутри каждой секции; основной брейкпоинт — ~1024–1080px.
- **Кнопка `.btn`:** градиент `goldShimmer`, `pill`-скругление, 3D-перспектива.
- **Тёмный/светлый ритм:** блоки чередуют `background: var(--dark)` и `background: var(--light)`.

## Ключевые технические решения
- **Отсутствие сборщика:** все изменения тестируются вручную в браузере.
- **Телефонная маска:** JS-функция `cleanPhone()` форматирует ввод в реальном времени.
- **Хранение cookie:** согласие сохраняется в `localStorage`; если значение 'rejected' — форма отклоняется.
- **SEO:** Open Graph-теги (og:title, description, image, type, url), sitemap.xml, robots.txt, preload шрифтов.
