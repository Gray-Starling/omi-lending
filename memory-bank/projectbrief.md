# Project Brief — OMI Lending

## Назначение
Русскоязычный одностраничный сайт (лендинг) компании **OMI** — производство корпусной мебели и продажа сантехники; комплексное оснащение ванных комнат. Сайт представляет продукты, шоурум, готовые решения, отзывы и форму сбора заявок.

## Цели
- Генерация лидов (заявок на расчёт/консультацию).
- Демонстрация собственного производства мебели.
- Убеждение клиента через социальное доказательство (отзывы 2GIS), готовые решения, FAQ.
- Стимулирование заказа через спецпредложение (скидка 30% на раковину при заказе тумбы).

## Границы проекта
- **Тип:** статический одностраничный сайт, HTML + CSS + JS, без серверной логики.
- **Домен:** omi-shop.ru — зарегистрирован, лендинг будет размещён на поддомене (название определяется).
- **Содержание:** `index.html` — лендинг; `politika.html`, `soglasie.html`, `cookies.html` — пустые правовые страницы-заглушки.
- **Ресурсы:** локальный каталог `assets/` (CSS, JS, шрифты, изображения, иконки, видео).
- **Внешние зависимости:** отсутствуют.

## Аудитория
Жители Владивостока и Приморского края, обустраивающие или обновляющие ванную комнату; ищущие индивидуальные решения с возможностью замера, дизайн-проекта и монтажа.

## Ключевые блоки страницы
1. Хедер (логотип, навигация, телефон, CTA-кнопка)
2. Hero-секция
3. Состав работ (продукты для ванной)
4. Сборка мебели (собственное производство)
5. Шоурум (одна сцена)
6. Готовые решения (мини-каталог, карусель)
7. Отзывы (карусель из 7 карточек, ссылка на 2GIS)
8. FAQ (аккордеон)
9. Спецпредложение (скидка 30%)
10. Форма связи (имя + телефон)
11. Футер (реквизиты ИП, ссылки, cookie-баннер)
