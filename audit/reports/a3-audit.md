## 4. Ответы на вопросы

### Логика клика по [data-topic] → запись в input[name="topic"] → показ .ctaform__topic — уже реализована в JS?

**Да.** Реализована в модуле строк 693–719:
- Глобальный `click`-слушатель (строка 709) ловит клик по `a[data-topic]`.
- `setTopic()` (строка 703) записывает значение в `input[name="topic"]`, обновляет `.ctaform__topic-text` и показывает строку `.ctaform__topic` (убирает `hidden`).
- Если клик по `a[href="#contacts"]` без `data-topic` — тема сбрасывается (строка 713–714).

### Кнопка сброса .ctaform__topic-reset — обрабатывается в JS?

**Да.** Строка 718: `reset.addEventListener('click', function () { setTopic(''); });` — очищает тему и скрывает строку.

### Есть ли баги или незавершённые места?

1. **Тема не передаётся при отправке формы.** Модуль валидации (строки 487–640) при `submit` не читает `input[name="topic"]`. В `alert()` выводится только имя и телефон. Если форма будет отправляться на сервер — `topic` уйдёт, но сейчас это не используется.

2. **Дублирование логики сброса.** Если кликнуть на CTA без `data-topic` (строка 75, 101, 176, 1099), JS сбросит тему (строка 713–714). Это корректно, но может быть неочевидно: пользователь кликнул «Рассчитать стоимость» в шапке — тема сбросилась, хотя ожидал бы увидеть «Комплексное решение для ванной».

3. **Нет data-topic у двух CTA в шапке/мобильном меню** (строки 75, 101). Они сбрасывают тему при клике. Если нужно, чтобы они тоже передавали контекст — надо добавить `data-topic`.

4. **hero-offer (строка 176) и FAQ-ссылка (строка 1099)** — не кнопки `.btn`, но участвуют в логике сброса темы. Это может быть неожиданно: клик по «Спросите менеджера напрямую» сбросит ранее выбранную тему.

5. **JS-генерируемые кнопки** (строка 221) используют шаблон `Решение «${s.title}»`. Если `s.title` пустой или содержит кавычки — возможны артефакты в `data-topic`.

## Резюме

- **Механизм работает:** data-topic → скрытое поле → отображение темы — всё реализовано.
- **Сброс темы** при клике на CTA без data-topic — корректное поведение.
- **Основной недостаток:** тема не участвует в отправке (только `alert`), но это вопрос бэкенда, а не логики data-topic.
- **Кандидаты на доработку:** CTA в шапке (75) и мобильном меню (101) не имеют data-topic.
