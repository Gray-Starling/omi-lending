## Анимация — ТОЛЬКО смена позиций
- transform+opacity .9s cubic-bezier(.33,.1,.25,1); никаких анимаций внутри карточки (решение клиента: не перегружать).
- Уходящая карточка уезжает за экран в свою сторону (lastDir, exitOff); входящая — невидимый прыжок за экран (transition:none + reflow) и плавный въезд. Пересечений в кадре нет.
- Маски до края экрана: width calc(50vw − 50% + 180px), сплошной градиент снаружи — карточка «проявляется» из темноты без жёсткой кромки.
- Клик по боковой карточке → в центр. Точки-табы.

## Автоплей и мобилки
- Автоплей 6s — только десктоп с hover; пауза на hover; отключён при (hover:none)/(pointer:coarse) и ≤900px.
- Мобилки: одна карточка, свайп + **видимые стрелки** (40px, подсказка свайпа), маски скрыты.
