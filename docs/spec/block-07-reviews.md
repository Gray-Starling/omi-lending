# Спецификация блока 7 «Отзывы» (V10)

**Статус:** УТВЕРЖДЕНО 2026-10-02  
**Файлы:** `index8.html` + `assets/css/style8.css`  
**Ритм:** 6 Готовые решения (dark) → **7 Отзывы (light)** → 8 FAQ (dark)

## Концепция
Реальные отзывы с 2GIS, оформленные в стиле 2GIS. Карточки фиксированной высоты 256px, длинные отзывы раскрываются по клику на кнопку «Читать полностью» (мгновенно, без анимации).

## Контент
- **h2:** «Что говорят клиенты»
- **Лид:** «Реальные отзывы тех, кто уже живёт с решением от OMI.»
- **7 отзывов** с 2GIS, текст **слово в слово** (включая опечатки: «качевенный», «огововренных», «подскажут , новые», «у ни зеркала», «аксесуары»).
- **Удалён отзыв Анны Кашкиной** (конфликт с ИП Кашкин).
- **Убрано количество отзывов** у клиентов (информация 2GIS, нам не нужна).
- **Сортировка:** свежие отзывы первыми (22.09.2026 → 28.06.2023).
- **Ссылка на 2GIS:** точная, `target="_blank"`.

## Структура карточки
- Аватар: круг 40px, цветной фон (7 разных цветов), инициалы белые жирные.
- Имя: Mulish SemiBold 600, 15px.
- Звёзды: 5 жёлтых SVG, 16px.
- Дата: серый, 13px.
- Текст: Mulish Regular 400, 15px, line-height 1.65.
- Кнопка «Читать полностью»: синяя (#2b6cb0), 14px, под текстом.

## Высота карточек
- **Все карточки:** `height: 256px` (или `max-height: 256px` для раскрываемых).
- **С кнопкой (1, 3, 5, 6):** `max-height: 256px`, текст обрезан до 4 строк (`-webkit-line-clamp: 4`), кнопка «Читать полностью». При клике — класс `is-expanded` → `max-height: 1000px`, текст полный, кнопка «Свернуть». **Без анимации.**
- **Без кнопки (2, 4, 7):** просто `height: 256px`.

## Карусель
- Drag мышью, touch-свайп, кнопки prev/next.
- Адаптивность: 3/2/1 карточек в ряд (≤900px → 2, ≤640px → 1).
- Gap 24px.
- Стрелки: круг 48px, тёмный фон, золотая рамка, hover → золото.

## Шрифты V10
- Mulish Regular 400 (тело) + SemiBold 600 (имена)
- Tenor Sans 400 (h2)
- Sansation Regular 400 (кнопки)

## Цвета
- Фон секции: `var(--light)` #efede8
- Текст: `var(--ink)` #1e1d1a
- Вторичный: `var(--gray)` #6e6a63
- Карточки: `var(--white)` #f5f4f1
- Звёзды: #ffb800
- Кнопка «Читать полностью»: #2b6cb0
- Вуаль сверху: `--from: var(--dark)` (переход от dark-блока 6)

## Правила V10
- Без ховера на карточках (только кнопки и стрелки).
- Без звёзд-стикеров.
- Fade-in при скролле + `prefers-reduced-motion` guard.
