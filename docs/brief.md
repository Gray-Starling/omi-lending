# OMI · BRIEF ДЛЯ НОВОГО ЧАТА

## Проект
Лендинг OMI (Владивосток) — компания, делающая комплексные решения для ванных комнат «от голых стен до готовой ванной» (финиш, БЕЗ чернового ремонта). Состав: собственная мебель (тумбы/пеналы/шкафы) + сантехника + душевые + зеркала/свет + аксессуары.
ЦА широкая, от эконома до премиума. Цель лендинга: №1 лиды (вывод на менеджера), №2 узнаваемость.
Статус: предпрод (V9), рабочая версия.

## Бренд
- Лого: `assets/icons/omi_logo.svg` (чёрный круг + золотые литеры #f1da8d).

- Тон: спокойный, уверенный, премиальный без пафоса.

## Ключевые принятые решения
- **Горячие предложения** — не отдельный блок, а компоненты `.sticker` (красная звезда-наклейка, rotate −8°, drop-shadow, выпирает за край фото через отрицательные top/right) + `.hotoffer` (оффер-строка с hairline-рамкой и кнопкой «Получить скидку»).
- **Скидки** (по согласованию с клиентом): полный комплект → раковина в подарок или скидка на комплект + скидка на остальную сантехнику; тумба → −30% на раковину (только раковина); точные цифры считает менеджер.
- **«Как мы работаем»** — таймлайн: grid 3 колонки (моб. 1 колонка с вертикальной линией), hairline-сегменты + золотая точка-маркер, золотая цифра 1–6 (без круга и ведущего нуля).
- **Иконки мессенджеров** — внешние файлы через `<img>` + `filter: brightness(0) invert(1)` (белый), при hover — золотой filter. Mask/background-color не работают.
- **Аватары** — `ava-1..8.png` через background-image + цветовой фолбэк, без текстовых инициалов.
- **TODO-ссылки** (правовые страницы, отзывы) — `href="about:blank" target="_blank" rel="noopener"` (пустая вкладка как маркер). Логотип ведёт на `index.html`.
- **Ссылки без :visited** — `a:visited { color: inherit }`.
- **Карусели** — 3 видимых (1 на ≤900px), автоплей 5s/6s, стрелки, drag + touch, пауза при hover.
- **Вуали между секциями** — `.soft-top::before` 10px.
