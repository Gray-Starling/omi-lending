## Проект
Лендинг OMI (Владивосток), наполнение ванных комнат. V9 (index.html/style.css/script.js) заморожена как старт. V10 — поблочная пересборка в изолированных файлах indexN/styleN; финальная сборка по assembly.md после одобрения всех блоков.
Модель: наполнение ванной комнаты в любом сценарии (после ремонта / обновление / отдельный шкаф); согласование на стадии ремонта — только опция. БЕЗ чернового ремонта. НЕ делаем: текстиль, свет.
Цель: №1 лиды, №2 узнаваемость. Критерий решений: каждый блок приводит клиента.

## Ключевые решения (не откатывать)
Хедер статичный; бургер 46px; ≤1024 меню в бургер; ≤640 кнопка в бургер, телефон по центру. Кнопка — «пластина золота» (shimmer, подъём без scale/свечения). Соцсети floating справа, графит, блик без золотой заливки. Hero 100vh + графитовые плашки с отрицательным отступом. Состав: светлый, карточки «иконка+заголовок+строка». Мебель: слайд-шоу (±<figure>), «Каждый сантиметр работает». Промо: заменяемый слот, оффер «тумба в заказе → −30% на раковину», один оффер на страницу. Везде: fade + reduced-motion + focus-visible; без hover на не-кнопках; без звёзд-стикеров.
