# OMI Landing

Лендинг для OMI (Владивосток) — компании, предлагающей комплексные решения для ванных комнат: собственная мебель, сантехника, душевые, зеркала и аксессуары «под ключ».

## Статус
**Предпродакшн (V9)** — финальная рабочая версия перед релизом.

## Быстрый старт
Проект статический (HTML + CSS + vanilla JS). Запуск — любым локальным сервером:

```bash
# Python
python3 -m http.server 8000

# Node.js (через npx)
npx serve .

# PHP
php -S localhost:8000

```

Открыть: http://localhost:8000

## Структура

omi-lending/

    └── README.md       # описание раздела docs

## Технологии
* HTML5 + CSS3 (custom properties, grid, flex)
* Vanilla JavaScript (ES5-совместимый синтаксис, без сборщиков)
* 3 шрифта: Mulish (200), Tenor Sans (400), Sansation (300)
* Адаптив: desktop 1500px max-width, tablet 900px, mobile 640px
* Без внешних зависимостей и библиотек

## Принципы
* Премиальный тёмный тон: золото #f1da8d как дозированный акцент на тёмно-коричневом фоне.
* Минимум цветов: красный #d32f2f используется ТОЛЬКО для стикеров-звёзд со скидками.
* Никаких фреймворков: весь код ручной, для полного контроля.
* Без конструкторов: сайт написан с нуля.
